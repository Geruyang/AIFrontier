# AI Frontier 1.5.0 验证记录

版本 1.5.0，build 7。Xcode 26.6，iPhone 17 Pro / iOS 26.5 Simulator，Release 配置；测试启用 ENABLE_TESTABILITY，不启用 DEVELOPER_ACCESS。

## 第一轮：扩源与刷新边界

- 新增目录数量与并发测试在修改前失败：来源只有 9 个，54 源压力用例同时发起了 54 个请求。改为滚动任务池后，最多 6 个并发且全部来源均被访问。
- 测试与实测发现部分 RSS 日期被漏解析，修复 EDT 命名时区与优先日期无效时的备用字段解析。对应两个日期用例通过。
- 109 个候选中保留 64 个有效端点，覆盖 52 个发布机构分组；生产请求、解析与筛选核验 64/64 成功，解析 3,687 篇、当月去重入选 197 篇。[完整清单](NEWS-SOURCES-1.5.0.md)和[结构化记录](NEWS-SOURCE-AUDIT-1.5.0.json)仅保存元数据，不复制正文。

## 第二轮：集成回归与独立复核

- 65 项逻辑测试、3 项相关界面测试全部通过：来源页按需打开、按来源名称搜索并显示类别、中文引导的大辅助字号布局。
- 最终 64 源目录落定后再次运行 65 项逻辑测试及来源搜索界面用例，均通过；截图显示 64 个来源。
- 独立复核确认目录和两份审计文档逐项一致，ID、名称、Feed URL 与重定向 URL 均唯一；公开记录无凭据、设备标识和文章正文。
- 已复核滚动请求池与原有取消清理、等待者恢复逻辑。本轮未声称重新执行全部 19 项界面用例；未修改流程的上一版结果保留在 [1.4 验证报告](VERIFICATION-1.4.0.md)。

## 第三轮：启动画面与发行包

- 原生启动 storyboard 已写入 Info.plist、XcodeGen 资源配置与 Xcode 项目；独立编译通过。
- 测试从实际应用资源加载启动页、品牌图形和背景色，在 320 × 568、568 × 320、1024 × 1366 点尺寸下验证文字与图形无歧义且不越界。
- 已目视检查 [402 × 874 点启动预览](images/launch-screen-1.5.0.png)及最终来源搜索截图。启动预览是实际 storyboard 的 UIKit 渲染，不是系统冷启动截图；不增加等待计时器。
- Release 真机归档、App Store 分发导出、通用模拟器构建和静态分析通过。构建仅有未使用 AppIntents 的元数据提取提示。
- 包审计确认版本 1.5.0 / build 7、最低 iOS 18、严格签名、有效分发描述文件、0 个设备标识、启动 storyboard 和隐私声明齐全；600 课 / 1,980 题与源码一致。模拟器包不含 XCTest 测试束。

## 验证边界

- 第三方 Feed 可用性是核验时快照，不等于永久可用，也不等于逐篇事实核查；同一发布机构可能提供多个频道。
- iOS 决定实际后台唤醒时机，不能保证固定五分钟后台运行。
- Apple 翻译引擎不能在模拟器运行；本次未进行 App Store 审核、真实订阅交易或真机冷启动检查。
- 沿用 1.4 的已知限制：本机 Intel / iOS 26.5 模拟器原生 Liquid Glass 底部导航的标签/图标渲染异常，在旧版及独立 TabView 示例均可复现，功能测试通过但该原生区域未完成视觉验收；需其他宿主或真机确认。未宣称该问题已修复或所有潜在缺陷已清除。
