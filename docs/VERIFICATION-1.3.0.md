# AI Frontier 1.3.0 验证记录

日期：2026-09-27。版本：1.3.0（build 5）。Xcode 26.6 / Swift 6，iPhone 17 Pro 模拟器 iOS 26.5；最低部署目标 iOS 18。

## 初始检查与改进

原有 38 项单元测试全部通过。新增回归先复现了“未及格也完成课程”和“清除学习记录删除资讯收藏”两个问题，再修正实现。完整改进清单见 [IMPROVEMENTS-1.3.0.md](IMPROVEMENTS-1.3.0.md)。

迁移可恢复旧版本缓存中仍有内容的收藏；如果旧版本已经删除文章内容、只剩收藏 ID，本次无法凭空恢复其标题和摘要。

新增实用功能：继续学习入口、按最近一次答题结果生成的待复习课程、独立保存的长期资讯收藏、搜索无结果提示和清除筛选。现有最好成绩继续保留；完成课程要求至少三分之二正确，待复习列表则保留任何仍有错题的最近一次测验。

## 构建与测试方法

Release 测试显式打开测试模块可见性，不定义 `DEVELOPER_ACCESS`；实际发行包单独构建，未打开测试选项。

```sh
xcodebuild -project AIFrontier.xcodeproj -scheme AIFrontier \
  -configuration Release \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.5' \
  ENABLE_TESTABILITY=YES ONLY_ACTIVE_ARCH=YES test
```

初次直接运行 Release 测试因默认关闭 testability 导致测试模块无法导入，按上述命令修正。新增筛选 UI 用例初次使用不完整的按钮标签，未定位到实际的“Preferred level, No filter”；已改为匹配标签前缀。复测时搜索栏因系统滚动收起而无法定位，最终改为直接检查返回后是否仍能看到基础级别课程，验证“全部”筛选的实际结果。这些初次失败保留在本机日志，未冒充成功记录。

真实四个官方新闻源检查成功：OpenAI 22 条、Google AI 3 条、DeepMind 6 条、NVIDIA 5 条，合并得到 36 条近期重要公告。此数为检查时的样本，不代表全行业覆盖。
