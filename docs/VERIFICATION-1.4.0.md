# AI Frontier 1.4.0 验证记录

版本 1.4.0，build 6。验证环境为 Xcode 26.6、iPhone 17 Pro / iOS 26.5 Simulator，Release 配置（测试时开启 ENABLE_TESTABILITY，不启用 DEVELOPER_ACCESS）。

## 三轮查找与修复

### 第一轮：实际流程与新闻

- 58 项逻辑测试通过，17 项界面测试中 16 项通过。
- 界面测试发现：从趋势主题进入文章列表后，点击文章未打开详情。原因是混用基于视图与基于值的导航；文章入口改为直接详情导航。
- 9 个来源使用生产请求器、解析器和筛选器实测全部成功。本次筛出 47 条近月重要资讯，包含 URL 去重与日期检查；低频来源允许暂时没有符合条件的条目。
- 新测试覆盖五分钟边界、失败节流、手动刷新、取消、并发刷新和主要模型名称识别。

### 第二轮：独立代码复核与回归

- 独立复核发现快速切换前后台的取消竞态：新前台任务可能依据旧请求的临时时间戳多等五分钟。
- 增加可取消的刷新完成等待机制，在旧请求清理完后重新判断刷新时机。两个异步回归用例覆盖清理重叠和等待者独立取消；复核确认无重复恢复与已发现的等待泄漏问题。
- 修复后 60 项逻辑测试全部通过；中文主页面、新手引导、资讯操作、趋势文章跳转 4 项界面回归全部通过。

### 第三轮：外观、可访问性与发行包

- 深色模式下的中文主页面、文章操作与趋势跳转 3 项界面回归通过。
- 截图复核发现旧大字号测试字符串未真正开启最大字号；改为 UIKit 提供的标准值，并断言标题实际高度大于普通字号。随后最大辅助字号下的资讯阅读/收藏、新手引导 2 项测试通过。此前仅启动成功的结果不被当作最大字号证据。
- 浅色、深色及最大辅助字号的内容布局已查看截图。按钮采用独立深青绿背景，避免暗色强调色配白字的对比不足。
- Release 真机归档、App Store 分发导出、通用模拟器构建与静态分析成功。
- 包审计确认：版本/build、最低 iOS 18、严格签名、有效分发描述文件、0 个设备标识、隐私声明和课程内容与源码完全一致。模拟器发行包不含 XCTest 测试束。

## 最终结果

60 项逻辑用例及 18 项不同界面用例均已通过。不是所有重复运行都计为新增测试，也没有把首轮失败抹去；汇总见 [verification-summary-1.4.0.json](verification-summary-1.4.0.json)。原始日志、xcresult 与截图保存在本地 `.build/verification-1.4.0/`。

[签名包审计](package-audit-1.4.0.json)与[二进制校验值](SHA256SUMS-1.4.0.txt)随源码发布。

## 边界

- iOS 实际后台唤醒时机由系统决定；测试能证明 300 秒策略及取消处理，不能证明固定五分钟后台执行。
- Apple 翻译引擎不在模拟器运行，中文界面与缓存流程采用隔离测试数据；真机语言包下载及引擎效果不在本次模拟器验证范围。
- 未进行 App Store 审核或真实付费订阅交易，也没有宣称所有潜在缺陷都已排除。
- 本机 Intel 模拟器截图中的系统 Liquid Glass 底部导航存在标签/图标缺失与选中效果异常；点击与无障碍导航测试通过，但该原生区域**没有完成视觉验收**。旧版 1.3.0 以及一个只包含原生 `TabView`、两个 `Text` 和两个 `Label` 的独立最小应用均复现，因此该问题不依赖本轮界面代码。打开 Simulator 窗口后仍复现。现有证据支持系统渲染/合成差异的推断，不能确认具体根因，也不能宣称真机正常；需要真机或其他宿主环境复核。对照截图为本地 `baseline-tabs.png` 与 `minimal-tabs.png`，未用截图处理掩盖该现象。
