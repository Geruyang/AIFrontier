# AI Frontier 1.4.0：界面与新闻改进

## 审查结论与修改

| 不足 | 修改 | 使用价值 |
| --- | --- | --- |
| 四个新闻源偏集中 | 接入 Microsoft AI、AWS、Hugging Face、MIT、Berkeley，扩展到九个源 | 覆盖更多产品发布、开源进展及大学研究 |
| 仅打开时更新，后台最早六小时 | 前台每五分钟检查，回到前台按需检查，后台最早五分钟请求 | 阅读期间持续获得新内容；真实执行仍服从 iOS 调度 |
| 首页充满操作说明、翻译和缓存过程 | 删除重复流程说明，来源及更新详情移至按需入口 | 首屏聚焦内容，保留必要异常和原文入口 |
| 页面重复白色列表，层级单一 | 深海蓝主卡、青绿/电光紫强调色、圆角内容卡、杂志式头条 | 学习进度、新闻焦点、趋势与收藏各有清晰主次 |
| 图表无法继续探索 | 主题直接跳转相关文章 | 从观察趋势自然进入阅读 |
| 搜索仅支持内容 | 增加发布者名称搜索 | 更容易关注特定机构 |
| 学习目标反复占据页面 | 保留为可展开的学习目标 | 有需要时阅读，不挤占课程浏览空间 |
| 暗色模式下亮色按钮与白字对比不足 | 操作按钮采用独立深青绿背景，正文强调色自适应 | 保持明暗两种外观下的可读性 |

## 界面设计

采用 UI UX Designer 插件的原生移动界面、改版与颜色指南，直接实现 SwiftUI 页面。保留系统四标签导航、系统搜索、下拉刷新、动态字体与原生返回行为。使用自绘轨道图形作为装饰，不依赖外部图片或动画；无持续动画，不增加后台消耗。主卡具有深海蓝渐变，内容区跟随明暗模式。

用户需要的来源署名、日期、原文、隐私、订阅条款和离线提示仍然存在。隐藏的是无须持续占据界面的执行说明。译文明确标识并可展开英文原文；来源声明可展开查看。

## 平台边界

没有新增服务器、账号、云端翻译或后台常驻机制。iOS 对后台刷新有系统调度限制，不能承诺每五分钟执行。新闻更新不等于事实核查，来源覆盖也不等于整个行业。
